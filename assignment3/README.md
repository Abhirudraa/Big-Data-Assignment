# Graded Assignment 3 – Week 4

## Objective

Use Google Cloud Dataproc and PySpark to calculate the total number of clicks that occurred in different time-of-day intervals.

The solution is implemented using both:

1. PySpark RDDs
2. PySpark DataFrames

SparkSQL is not used.

## Input Data

The input file is:

`click_file.txt`

It contains two columns:

- `user_id`
- `timestamp`

Example:

```text
user_id,timestamp
u001,2025-08-01 09:03:23
u012,2025-08-01 12:37:50
u006,2025-08-01 06:57:32
```

## Time-of-Day Bins

Clicks are grouped into the following intervals:

- 0–6 hours
- 6–12 hours
- 12–18 hours
- 18–24 hours

## GCP Architecture

```text
Input CSV
   |
   v
Google Cloud Storage
   |
   v
Google Cloud Dataproc
   |
   +--> PySpark RDD implementation
   |
   +--> PySpark DataFrame implementation
   |
   v
Google Cloud Storage
   |
   v
Output
```

## Execution

The PySpark program was executed on a Google Cloud Dataproc cluster.

Cluster configuration:

- Cluster name: `assignment3-cluster`
- Region: `asia-south1`
- Zone: `asia-south1-c`
- Configuration: Single-node
- Machine type: `e2-standard-2`
- Dataproc image: `2.2-debian12`

The input file was stored in Google Cloud Storage before submitting the Spark job.

## Results

Both RDD and DataFrame implementations produced the same results:

| Time Interval | Click Count |
|---|---:|
| 0–6 | 44 |
| 6–12 | 53 |
| 12–18 | 48 |
| 18–24 | 55 |

Total clicks: **200**
