# Big Data Assignment – Week 1

## Assignment Overview

This assignment demonstrates the use of **Google Cloud Platform (GCP)** and **Google Cloud Storage (GCS)** to analyze a text file and identify the longest line(s) based on character length.

The program was developed and executed on a **GCP Workbench VM**. The input file is stored in a GCS bucket, downloaded by the Python program, analyzed, and the resulting output is uploaded back to the GCS bucket.

## Files Included

### `task.py`
The main Python program for the assignment.

It:
- Connects to Google Cloud Storage using the Google Cloud Storage Python client.
- Downloads `test.txt` from the GCS bucket.
- Reads the text file line by line.
- Calculates the character length of each line.
- Identifies the longest line.
- Handles multiple lines having the same maximum length.
- Prints the results in the terminal.
- Creates `output.txt` containing the results.
- Uploads `output.txt` back to the GCS bucket.

### `test.txt`
The sample input text file used for testing the program.

It contains multiple lines of different lengths, including two lines with the same maximum length. This allows the program to demonstrate that all longest lines are reported when there is a tie.

### `output.txt`
The output generated by `task.py`.

It contains:
- The maximum line length.
- All lines that have that maximum length.

### `week_1.ipynb`
The Jupyter Notebook used during development and execution on the GCP Workbench environment.

It contains the steps used to:
- Create the sample input file.
- Connect to GCS.
- Upload the input file.
- Download and analyze the file.
- Generate the output.
- Upload the output file to GCS.
- Verify the successful execution.
