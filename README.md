# Graded Assignment 2 – Week 3

## GCS-Triggered Google Cloud Function for Finding Longest Lines

### Overview

This assignment implements an event-driven solution on **Google Cloud Platform (GCP)** to identify the longest line(s) in a text file stored in **Google Cloud Storage (GCS)**.

A **Gen 2 Google Cloud Function** is triggered automatically whenever a file is uploaded to the configured GCS bucket. The function downloads the uploaded file, determines the maximum line length, prints the longest line(s) to **Cloud Logging**, and saves the result as `output.txt` back into the same GCS bucket.

If multiple lines have the same maximum character length, all such lines are included in the output.

---

## GCP Architecture

```text
                 Google Cloud Storage
                         │
                         │ File uploaded
                         ▼
                  Eventarc Trigger
                         │
                         ▼
              Google Cloud Function
                 find-longest-lines
                         │
                ┌────────┴────────┐
                │                 │
                ▼                 ▼
        Cloud Logging        output.txt
                                  │
                                  ▼
                         Same GCS Bucket
```

### Workflow

1. `input.txt` is uploaded to the GCS bucket.
2. The GCS upload generates an object-finalized event.
3. Eventarc triggers the `find-longest-lines` Cloud Function.
4. The function downloads the uploaded file.
5. Each line is checked for its character length.
6. The longest line length is identified.
7. All lines having that maximum length are collected.
8. The results are printed to Cloud Logging.
9. The results are written to `output.txt`.
10. `output.txt` is saved back into the same GCS bucket.
11. The function ignores `output.txt` when it is triggered again, preventing recursive processing.

## Included Files

### `main.py`

This is the main Python source code for the Google Cloud Function.

The function:

- Receives the GCS event.
- Identifies the uploaded file and bucket.
- Downloads the file using the Google Cloud Storage client.
- Reads the file line by line.
- Determines the maximum character length.
- Collects all lines with the maximum length.
- Prints the result to Cloud Logging.
- Creates `output.txt`.
- Uploads `output.txt` back to the same GCS bucket.
- Ignores `output.txt` on subsequent GCS events to prevent an infinite trigger loop.

The Cloud Function entry point is:

```text
find_longest_lines
```

---

### `input.txt`

This is the test input text file used to demonstrate the Cloud Function.

It contains lines of different lengths, including a deliberately repeated longest line. This allows the assignment requirement of reporting **all lines sharing the maximum length** to be tested.

The file is uploaded to the GCS bucket to trigger the Cloud Function.

---

### `output.txt`

This file contains the result generated automatically by the Cloud Function.

For the provided test input, the function identified:

```text
Longest line length: 121
```

The longest line occurs twice in the input, so both occurrences are included in the output.

The file is generated by the Cloud Function and stored back in the same GCS bucket.

### Google Cloud Functions – Gen 2

Function:

```text
find-longest-lines
```

Runtime:

```text
Python 3.12
```

Region:

```text
asia-south1
```

The function performs the longest-line analysis whenever a file is uploaded to the configured GCS bucket.

### Eventarc

Eventarc connects the GCS object-finalized event to the Cloud Function.

The trigger is based on:

```text
google.cloud.storage.object.v1.finalized
```

This means the function is automatically invoked when an object is successfully created in the bucket.

### Cloud Logging

Cloud Logging is used to record the results produced by the function.

The function logs the longest line length and all lines having that maximum length.
